# بناء (Benaa) — نظام إدارة شركات المقاولات SaaS

نظام SaaS متكامل مبني بلغة **PHP** و **MySQLi** لإدارة شركات المقاولات والإنشاءات، بتصميم عربي احترافي (RTL) متعدد المستأجرين (Multi-Tenant) — كل شركة مشتركة تعمل بمعزل كامل عن بيانات الشركات الأخرى.

## المزايا الرئيسية

- **معالج تثبيت تفاعلي**: تثبيت النظام بالكامل من المتصفح دون الحاجة لسطر الأوامر — فحص المتطلبات، إعداد قاعدة البيانات وإنشاؤها، استيراد الهيكل، وإنشاء حساب مالك النظام، كل ذلك خطوة بخطوة.
- **متعدد الشركات (Multi-Tenant)**: كل شركة تسجّل حسابها الخاص وتبدأ بفترة تجريبية مجانية 14 يوماً.
- **إدارة المشاريع**: مشاريع، عملاء، عقود (مع رفع الملفات)، متابعة نسبة الإنجاز.
- **الشؤون المالية**: فواتير ببنود متعددة وضريبة قابلة للتخصيص، تسجيل دفعات، طباعة الفواتير، مصروفات مصنّفة.
- **الموارد البشرية**: بيانات الموظفين، الحضور والانصراف اليومي، توليد وصرف الرواتب الشهرية.
- **المخزون والمشتريات**: الموردون، مخزون المواد مع تنبيه انخفاض المخزون، أوامر الشراء التي تُحدّث المخزون تلقائياً عند الاستلام.
- **نظام صلاحيات قابل للتخصيص بالكامل**: كل شركة (من صفحة "الأدوار والصلاحيات") تحدّد بنفسها أي وحدات النظام مسموحة لكل دور من موظفيها (مدير نظام، مدير مشاريع، محاسب، مهندس، موظف) عبر مصفوفة تفعيل/تعطيل بسيطة — بينما يملك مالك الشركة دائماً كل الصلاحيات.
- **لوحة تحكم مالك النظام (Super Admin) كاملة**: إدارة الشركات المشتركة (تفعيل/إيقاف/تمديد الاشتراك)، عرض تفاصيل كل شركة (مستخدمين، استخدام، حذف نهائي)، إدارة خطط الاشتراك (CRUD كامل)، سجل نشاطات شامل عبر كل الشركات، إدارة حسابات المشرفين المتعددين، وملف شخصي لتحديث بيانات المشرف.
- **تقارير**: ملخص مالي، ربحية المشاريع، تحليل المصروفات، ملخص الحضور الشهري.
- **تصميم احترافي**: واجهة عربية (RTL) عصرية مبنية على Bootstrap 5 وخط Cairo مع رسوم بيانية (Chart.js) — جميع مكتبات Bootstrap وChart.js مُضمَّنة محلياً داخل المشروع (`assets/vendor/`) وليست معتمدة على أي CDN خارجي، بحيث تعمل الواجهة بكامل تصميمها حتى على استضافات بلا وصول خارجي للإنترنت أو خلف سياسات شبكة مقيّدة.

## المتطلبات

- PHP 8.0 أو أحدث مع امتداد `mysqli` مفعّل.
- MySQL 5.7+ أو MariaDB 10.3+.
- خادم ويب (Apache/Nginx) يدعم `.htaccess` (لـ Apache) أو إعداد مكافئ.

## خطوات التثبيت (معالج التثبيت — الطريقة الموصى بها)

1. ارفعوا ملفات المشروع كاملة إلى جذر الاستضافة.
2. تأكدوا أن المجلدين `uploads/` و `config/` قابلان للكتابة من قبل خادم الويب:
   ```bash
   chmod -R 755 uploads/ config/
   ```
3. افتحوا المتصفح على `https://your-domain.com/install/index.php` واتبعوا الخطوات:
   1. فحص متطلبات التشغيل تلقائياً.
   2. إدخال بيانات اتصال قاعدة البيانات (سيتم إنشاؤها تلقائياً إن لم تكن موجودة).
   3. استيراد هيكل قاعدة البيانات والبيانات الأولية.
   4. إنشاء حساب مالك النظام (Super Admin) الخاص بكم.
   5. إنهاء التثبيت — يُنشئ المعالج ملف `config/installed.php` تلقائياً ببيانات الاتصال.
4. **لأسباب أمنية، يُنصح بشدة بحذف أو حماية مجلد `install/` من الخادم بعد التأكد من نجاح التثبيت.**

### التثبيت اليدوي (بديل)

إن رغبتم في التثبيت دون معالج (مثلاً في بيئة تطوير آلية)، يمكن تجاوز المعالج بالكامل عبر متغيرات البيئة:
```bash
mysql -u root -p -e "CREATE DATABASE benaa CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -p benaa < database/schema.sql
export DB_HOST=localhost DB_USER=benaa_user DB_PASS=your_password DB_NAME=benaa
```
وجود `DB_HOST` كمتغير بيئة يُغني عن الحاجة لملف `config/installed.php` ويعتبره النظام "مثبتاً".

## الدخول لأول مرة

- **مالك النظام (Super Admin)**: بالحساب الذي أنشأتموه في الخطوة 4 من معالج التثبيت، عبر `/modules/auth/login.php`.
- **تسجيل شركة مقاولات جديدة**: `/modules/auth/register.php` (فترة تجريبية 14 يوم تلقائياً).

## هيكل المشروع

```
config/           إعدادات التطبيق؛ config/installed.php يُنشأ تلقائياً بواسطة المثبّت (غير مرفوع في المستودع)
database/         ملف هيكل قاعدة البيانات (schema.sql)
includes/         الطبقات المشتركة: bootstrap, auth, functions, header/sidebar/footer
install/          معالج التثبيت التفاعلي
assets/           CSS وJS، بما فيها مكتبات Bootstrap/Chart.js المضمَّنة محلياً (assets/vendor/)
modules/          كل وحدة من وحدات النظام في مجلد مستقل (auth, dashboard, clients, projects, roles, ...)
superadmin/       لوحة تحكم مالك النظام الكاملة (الشركات، الباقات، النشاطات، المشرفون، الملف الشخصي)
uploads/          الملفات المرفوعة (عقود، مرفقات مصروفات، شعارات الشركات)
```

## نظام الأدوار والصلاحيات

كل مستخدم في الشركة يحمل أحد الأدوار التالية: **مالك الشركة** (صلاحية كاملة دائماً، غير قابلة للتقييد)، **مدير النظام**، **مدير مشاريع**، **محاسب**، **مهندس**، **موظف**.

من صفحة **الأدوار والصلاحيات** (متاحة لمالك الشركة ومدير النظام فقط)، يمكن لمدير الشركة تفعيل أو تعطيل وصول كل دور (عدا المالك) لكل وحدة من وحدات النظام (العملاء، المشاريع، الفواتير، الموظفون، ...) عبر مصفوفة تفعيل/تعطيل بسيطة، ليخصص صلاحيات موظفيه بالضبط كما يحتاج شركته. الوحدات غير المخصَّصة بعد تعمل بمصفوفة افتراضية معقولة حسب الدور.

## الأمان

- كلمات المرور مخزّنة عبر `password_hash()` (bcrypt).
- جميع الاستعلامات تستخدم Prepared Statements عبر MySQLi لمنع حقن SQL.
- حماية CSRF على جميع النماذج.
- عزل بيانات كل شركة (company_id) على مستوى كل استعلام.
- ملفات الإعداد والتضمين محمية عبر `.htaccess` من الوصول المباشر.
- معالج التثبيت يرفض العمل مجدداً بمجرد وجود `config/installed.php`، ولا يمكن الوصول لأي صفحة في النظام قبل إتمام التثبيت.

## الترخيص

هذا المشروع مقدَّم كنقطة انطلاق قابلة للتخصيص حسب احتياجات شركتكم.
